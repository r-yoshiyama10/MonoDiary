## MonoDiary とは

LINE に送ったテキストメッセージを、AI が自然な日記文に変換して記録するアプリです。

「今日こんなことがあった」と LINE に送るだけで、Gemini が文体を整え読みやすい日記として保存されます。Web アプリ側では一覧・検索・詳細表示で過去の記録を振り返ることができます。

## 技術スタック

| レイヤー | 技術 |
|---|---|
| フロントエンド | React / TypeScript / Vite / Tailwind CSS |
| バックエンド | Go / Echo  |
| データベース | PostgreSQL  |
| AI | Google Gemini API（gemini-2.5-flash） |
| 外部連携 | LINE Messaging API / LINE Login |
| インフラ | Docker Compose |

## 機能紹介

### LINE で日記を記録する

LINE にテキストを送信すると、Gemini が日記文に整形してデータベースへ保存し、変換結果を LINE で返信します。

## 今後改善予定の機能

| 機能 | 概要 |
|---|---|
| LINE からの Web 導線 | リッチメニューや LIFF からそのまま Web アプリへ遷移できるようにする |
| 画像の取り込み | 写真付きでエントリを残せるようにし、マルチモーダルで日記を生成する |
| 生成結果のリトライ・修正 | 気に入らない場合に数回限り再生成や修正依頼ができるようにする |
| 文体・トーンのパーソナライズ | 過去エントリの傾向を蓄積し、その人らしい文体で日記を生成できるようにする |
